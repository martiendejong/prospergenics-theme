### AI Software Lifecycle
**Level:** Intermediate  
**Duration:** 15 min setup + ongoing  
**Instructor:** Martien de Jong  
**URL:** https://test.prospergenics.com/courses/ai-software-lifecycle/

Set up a fully autonomous AI development system and manage your entire software lifecycle from your phone. In 10 practical steps you will install an AI coding agent, give it persistent memory, use Git for version control, run multiple agents in parallel with worktrees, connect a task manager, automate deployment, add AI code review, and orchestrate everything from a conversation on your phone.

**Topics covered:** Claude Code, Git, Worktrees, Task management, Deployment pipelines, Multi-agent workflows, Mobile access

**Who it is for:** Developers and technical entrepreneurs who want to move faster without hiring a team, and anyone curious about autonomous AI development.

**Prerequisites:** Basic terminal knowledge. No deep programming experience required.
